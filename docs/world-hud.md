# 温泉前とHUDの整理（2026-10-25）

既存のクリーム色・青緑・丸角の表現を引き継ぎ、街を見渡す中央の空間を広くした。館・経路・ツアー・通常表示のURLは維持する。

- 温泉前の技術オブジェ5個を台座と文字ごと削除。技術の本文は街の案内と既存URLから読める。
- 上部左に通常表示、上部右にBGM・画質・街の案内。画質は「高／低」の状態も表示する。
- 下部左に常ダッシュと街全体を見る、下部右に縦並びの＋／−。全体表示からは同じボタンで人物に戻る。
- 常ダッシュは押すたびにON／OFFを切り替え、ONの間は通常の移動でも5m/sで走る。初期値はOFF。
- 停止・キーボード・自転車・ジャンプ・人物に戻る専用ボタンと説明帯を常設HUDから外した。キーボード操作は維持し、自転車は現地のラベルから乗車・降車・取得失敗時の再読み込みができる。
- 名前と所属は入口の紹介で表示。見出しと操作状態の読み上げは維持する。HUDのDOM順も上部の表示順に合わせる。
- タップ対象は44px以上。ノッチ・ホームバーの余白を考慮し、画質と案内のパネルは画面内に収める。

`WorldCanvas`の準備状態は`.worldSurface[aria-busy="false"]`で示し、削除したキーボードボタンに検証が依存しないよう更新した。

## 確認

`tests/browser/world-hud.js`で、削除前に温泉前の5個が残って失敗することを確認し、削除後の成功を確認。1440×900、390×844、320×568、844×390で、常設HUDが8操作（＋と−は別々）、重なり・はみ出しなし、タップ対象、キーボード順序、常ダッシュの移動距離、BGMのON／OFF、画質・地図パネルを確認する。

単体テスト95件・型チェック・本番ビルドが成功。`world-ux.js`、`world-halls.js`、`world-ux-loading.js`、`hall-navigation.js`、`onsen.js`、`security.js`で、操作・ツアー・履歴・直接URL・読み込み失敗・6館への徒歩・自転車・温泉・画質・BGM・CSPの回帰を確認。画像と結果はローカルの`output/playwright/hud-*`。

アクセシビリティ検証で見つかったBGMの状態文字のコントラストと、常ダッシュの読み上げ名を修正した。Lighthouseのアクセシビリティは100。axeで4画面サイズ×入口・探索・画質設定・地図・館内・通常表示の24状態を検証し、対象WCAGルールの検出0件。QA時のみ検査スクリプトを許可し、製品のCSPは緩めていない。

HUD変更後もスマホ幅390×844・CPU 4倍低速化で、5秒間の移動の実描画は通常画質・低設定とも約60FPS。p95の描画間隔は23.9ms／18.1ms、最大31.0ms／18.9ms。開発PC上のエミュレーションで、スマートフォン実機の測定ではない。測定方法は`world-frame-rate.md`と同じ。結果は`output/playwright/hud-frame-rate.txt`。
