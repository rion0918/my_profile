# 街とポートフォリオをつなぐ仕上げ

## 目的と保持するもの

「60点から100点へ」という依頼を、初めての訪問でも作品と本人を知れ、探索自体にも記憶に残る反応がある体験として実装する。点数の自己申告は合格根拠にしない。全画面Three.js、現地時刻、配色、りおまるの立体文字、徒歩と自転車、猫と鳥、プロフィールの事実、通常表示、既存URLは保持する。公開や有料サービスは行わない。

## 実画面の監査

`output/playwright/polish-before-1440.png`, `polish-before-390.png`, `polish-before-product.png`を確認した。

- 初期画面は名前と「学生エンジニア」だけで、街がポートフォリオであることや代表作への入口が弱い。
- 地図がなく、全体表示だけでは現在地と情報の対応を把握しにくい。
- 作品詳細は文章のみ。実際のUIを制作していることが伝わらない。
- 操作は同じ強さの矩形ボタンが並び、モバイルでは案内も小さい。
- 猫は造形と待機動作があるが、触れたときの反応がない。

色はアプリコット・コーラル・青緑・クリーム、操作の墨色は紫がかった濃色。街のディテールを主役にして、HTMLの操作は落ち着いた読みやすさへ整理する。通常表示のページ構成・見出し・URL、サイトのwordmarkは変えない。

## 実装と確認の順序

1. 実在する作品の画面を共通データに追加し、詳細と作品一覧・街の展示へつなぐ → 出典・画面サンプルの性質・ファイルの存在、PC/スマホで可読性を確認。未確認の実績や開発体制は補わない。
2. 到着の案内と操作UIを整理 → 初回・再訪・直接詳細URL・読み込み失敗・Reduced Motionで操作が妨げられないことを確認。
3. 案内に実際の街路と現在地の地図、読む/歩くの選択を追加 → 全4棟と港へ向かえること、手動操作で中断できること、キーボードとタップで使えることを確認。
4. 猫をなでたときの反応を追加 → 足や建物の選択と競合せず、近くからキーボードでも操作でき、Reduced Motionでは静かな反応にする。

## 合格の根拠

- 1440×900、1920×1080、390×844で画面を撮影し、初期の主役・操作・作品の内容が見える。HTMLの横はみ出しがない。
- 作品を歩かずに開ける。作品の画面は実在の本実装または本実装コンポーネントのサンプルであり、生成した偽UIを使わない。
- 地図と街の配置が一致し、現在地が更新される。目的地まで既存の経路探索を使って移動する。
- 新しい状態遷移・入力処理は失敗するテストから追加し、既存の移動・入館・時刻・動物・物理・BGMのテストを通す。
- 直接URL、戻る/進む、閉じた後の位置、通常表示、WebGL失敗時の導線をブラウザで確認する。
- モバイル相当条件で移動中のフレーム間隔p95が33.3ms以内。実機スマホとSafariの未確認は別記する。
- 所有するローカルの確認環境でレビューできる。外部公開はしない。

## 実装結果と根拠（2026-10-24）

初回だけ表示する到着の案内を追加し、作品をすぐに読むか、街を歩くかを選べるようにした。操作・BGM・案内をクリームと青緑へ揃え、44px以上の操作領域を確保した。街の案内には既存の配置データから作った地図と現在地を表示し、全4棟と港へ既存の経路探索で移動できる。6つのHTML詳細、通常表示、履歴、直接URLは維持した。

YoinとPop Reminderの実際の画面を作品一覧・詳細・街の展示台へ追加した。出典、サンプルデータの性質、ファイルのハッシュは `public/images/projects/SOURCES.md` に記録。作品名、説明、技術、本人の実績は既存データを維持した。展示台の画像は近づいてから読み込み、静止設定でも画像到着時に再描画する。

猫はタップ・クリックで近くまで歩いてなでられ、近くではFキーまたは「猫をなでる」ボタンでも操作できる。人物は猫の横へ移動して手を伸ばし、猫は目を細めて短いハートで反応する。自転車に乗ったままでは実行しない。Reduced Motionでは腕とハートを動かさず、猫の目による静かな反応を残した。猫7匹・地上の鳥6羽・上空の2群×3羽の既存配置と環境更新を利用し、動物専用の追加タイマーは作っていない。

新しい接近処理、腕の動き、画像、地図は実装前の失敗から確認した。ブラウザで見つかった、猫が人物の後ろへ隠れる接近位置、長い詳細で閉じる操作が消える問題、初回案内から詳細を閉じた際のフォーカス消失、Reduced Motionで展示画像が届いても反映されない問題も、再現確認の後に修正した。最後の負荷測定で案内の透明な領域がBGMへのタップを遮ることが分かり、コンテナをポインターの対象から外して、見えている要素だけで入力を受けるように修正した。

390×844・DPR 3（描画DPR 1）・CPU 4倍低速化・BGM再生で、猫と地上の鳥がいる広場を徒歩で往復し、上空の群れが飛ぶ時間帯を6秒測定。376サンプルのrAF間隔p95は18ms、最大20ms、未処理例外なし（`polish-flight-performance-result.txt`）。実画像を読み込んだYoinの展示前でも同条件で376サンプル、p95 18ms・最大20msだった（`polish-exhibit-performance-result.txt`）。これはPC上のエミュレーションであり、スマホ実機・Safariの測定ではない。

さらに夜・BGM再生・同じモバイル相当条件に下り4Mbpsと150ms遅延を加え、物理自転車で走行。5秒・313サンプルのp95は18ms、最大19ms、区間変位26.3m、BGM再生継続・未処理例外なし（`polish-performance-result.txt`）。初期描画まで約4.1秒だった。

最終の静止画は `output/playwright/final-welcome-1920.png`, `final-welcome-390.png`, `final-welcome-1440.png`（夜）と同幅の `final-guide-*.png`。実際のブラウザ操作を記録した `portfolio-polish.mp4` は約9.6秒・音声なし。初回案内、猫への接近となでる反応、街の地図、Yoinの実画面へ進む。生成した映像ではない。
