## 今回の改修

約80×70の街を、砂浜と海で囲む。通常の追従視点では街全体が収まらない。入口広場、アトリエ、技術の庭、キャリア展示通り、Yoinスタジオ、Pop Reminderパビリオンを街路で接続する。内陸には2つの池を配置。海岸から約2mの浅瀬まで歩け、その先は深い海として進行を止める。壁・池・木・花壇・ベンチ・看板も衝突対象にする。

Next.js / React / Three.jsと静的書き出しを継続。3D専用のクライアントチャンクを遅延ロードし、通常表示の既存レイアウトは維持。室内探索、音、有料素材、外部公開は含まない。

配色はBruno Simonの参考画面に合わせ、アプリコットの舗装、黄緑とコーラルの植栽、ターコイズの水面、クリーム色の壁へ変更。青紫の補助光で暗い影を持ち上げ、案内UIも同系色で統一した。

初期広場のRIONと地面の英語表記を撤去し、「りおまる」の立体文字を設置。丸いコーラル色の台座、面取りした厚みのある文字、青緑のリングと金色の丸を組み合わせる。文字は初期カメラへ向けて回転し、スマホ幅でも4文字が収まる。主街路の外に設置し、描画位置と共有した回転後の範囲を衝突判定に使う。Zen Maru Gothic Blackの4文字だけを変換したJSONは9,665 bytesで、出典・ライセンス・再生成方法は[フォント記録](../components/world/assets/RIOMARU-FONT.md)に残す。

## 人物

`public/models/rion-walker.glb`は、QuaterniusのCC0素材から加工した骨格付きモデル。短髪、テラコッタの上着、パンツ、スニーカー、バッグ、ファスナーとポケットを持つ。頭を1.45倍に調整。元の骨格とIdle / Walk / Runを使い、AnimationMixerで重みを滑らかに切り替える。

歩行速度は2.775 m/s（従来1.85 m/sの1.5倍）、ダッシュは4.6 m/s、浅瀬では1.1 m/s。通常歩行ではWalkクリップを維持し、ダッシュの速度域でRunへつなぐ。PCはShiftを押している間、スマホは「ダッシュ」ボタンで切り替える。モデルの接地中の足の後方速度をサンプリングし、歩行の中央値1.318 m/s、走行3.018 m/sを基準にクリップ速度を調整する。移動距離から実速度を求めるため、壁に阻まれた状態では待機へ戻る。`prefers-reduced-motion`では待機・歩行・走行のアニメーションと旋回・カメラの補間を抑える。

素材の出典、CC0、入力ファイルのハッシュ、加工と再生成手順は[モデルのライセンス記録](../public/models/LICENSE.md)。加工スクリプトは`scripts/build-character.mjs`。モデルは同一オリジンから配信し、閲覧時に外部素材サイトへアクセスしない。

## 配置・移動・入館

- `lib/world-layout.ts`: 4棟の寸法、街路、看板、植栽、水辺、個別の壁、入口の外側・内側。
- `lib/world-navigation.ts`: 人物半径0.32、0.5単位の事前生成歩行グリッド、A*探索。描画と共通の海岸の輪郭、海底の高さ、浅瀬の進入限界を持つ。ダッシュ移動も0.1単位で細分し、壁・海岸のすり抜けを防ぐ。
- `lib/world-jump.ts`: 高さ約0.86m・滞空約0.7秒のジャンプ。空中の再ジャンプを拒否し、着地で地面の高さへ戻す。
- `lib/street-network.ts`: 舗装のポリゴン結合、交差点の角の丸め、外周だけの縁石。
- `lib/world-entry.ts`: 前フレームから入口を内向きに越えた場合のみ発火。表示中の重複を防ぎ、閉じると外へ戻す。入口から離れるまで再発火を抑止。
- `components/world/create-world.ts`: 建築、家具、街路、看板、植栽、照明。静的メッシュとインスタンスを16単位の区画にまとめ、フラスタム外の描画を抑える。画面上で人物を隠す手前の建物・植栽は、人物の胴体に重なる範囲を透かす。
- `components/world/create-streets.ts`: 石張りの舗装、縁石、放射状の広場。
- `components/world/create-coast.ts`: 砂浜と傾斜した海底。
- `components/world/create-water.ts`: 海・池の水面、深さの色変化、浅瀬の光、岸の泡、波紋、周囲の反射。
- `components/world/WorldCanvas.tsx`: 追従カメラ、ドラッグ、全体表示、入力、ダッシュ、扉の開閉、入館とHTML詳細の接続。
- `components/world/load-character.ts`: GLBとアニメーション。

通常カメラは俯角を約22度から約28度へ上げた。PCの縦の表示範囲12.6、スマホ10.2を維持し、初期広場の「りおまる」がスマホでも切れないよう追従位置も調整する。全体表示は独立した距離を維持する。

自然物は湾曲した薄い葉、葉脈、樹皮の凹凸、先細りの枝、5本ずつ束ねた草、変形した岩と頂点色で作る。葉と草は風でわずかに動き、区画ごとのインスタンス描画を維持する。

海と池は共通の水面シェーダーで、異なる方向へ流れる2層の波紋、角度による反射、浅瀬の光の揺らめき、深さによる青緑の濃淡を描く。海は岸の泡と人物の周囲の波紋も持つ。外部の水面テクスチャは取得せず、128×128の波の法線・光の模様を生成して共有する。

周囲の街・木・人物はThree.jsのReflectorで実際のシーンを反射する。海面と池の水位に対応した2つの反射画像を使い、同じ水位の2つの池は共有する。PCは512×512で約30fps、スマホ幅は256×256で約15fpsを上限とし、視野内に水があるときだけ更新。波紋は通常の描画フレームで動かす。反射時は水面を隠して再帰を防ぎ、シャドウを再計算しない。動きを減らす設定では波・浅瀬の揺らめき・足元の波紋を静止させる。海岸の移動境界と池の衝突判定は維持する。

道路の描画と植栽の配置は同じCatmull–Rom曲線と道幅を使う。曲線を約0.25単位で分割して空間索引を作り、樹木は舗装から2.4、草は0.35の余白を確保。樹木37本を建物・池・展示・ベンチの外側へ配置し、樹冠と根元の花壇も通路に重ねない。岸辺の岩も大きさに応じて舗装を避ける。木の衝突範囲は移動後の配置から生成する。

地面タップはA*経路に沿って歩く。入口の扉・「入る」マーカーのタップでは入口内側まで移動する。建物・看板・技術展示・建物ラベル・街の案内からは、その場で詳細を開ける。Spaceまたは画面の「ジャンプ」で跳べる。移動中も使用でき、壁・水辺の平面衝突は維持する。空中で入口を越えたときは、入口内に着地してから詳細を一度だけ開く。膝は人物の左右軸で前へ曲げ、肘も連動させる。接地用の影とリングは地面に残す。動きを減らす設定でも明示的なジャンプ操作と着地は動作する。WASD / 矢印キーはワールドにフォーカスしている時だけ有効。7px以上のドラッグは移動・選択と区別する。

詳細中は人物・描画を停止。閉じると入館した入口の外側に復帰する。人物とカメラは`portfolio-position-v2`に保存し、小島時代の位置は使わない。保存時に入口内側の位置を外側へ正規化し、詳細を表示したままの再読み込みでも室内に取り残されないようにする。

人物モデルの取得は街のジオメトリ作成前に開始する。街のローカルジオメトリは一度生成し、区画ごとに描画をカリングする方式で、歩行中の区画ダウンロードはない。初回シェーダーは`compileAsync`で準備する。待機時は呼吸のために描画し、詳細中・非表示タブ・フォーカス喪失では停止する。アンマウントでGPU資源・ミキサー・RAF・イベントを解放する。

スマホは描画DPR 1・リアルタイム影なし。PCはDPR最大1.5・VSMシャドウ。両方でアンチエイリアスを使用する。

## 検証方法

```
npm test
npm run typecheck
npm run build
npm run dev
```

Node組み込みテストでTypeScriptの型除去を使うためNode 22.18以降が必要。今回の実行はNode 26.4.0。既存の`next lint`スクリプトは検証に使用していない。

移動・衝突・入館のテストは実装前のREDを確認し、実装後にGREENを確認。植栽の回帰テストでも変更前の道路との重なりを検出してから修正し、現在は25件が成功する。歩行速度1.5倍・ダッシュと水中速度の維持、旧RIONの位置を含む主街路の通行、速歩きでもWalkの姿勢を保つことを追加確認した。独立して生成した曲線を密にサンプリングし、全街路・入口・広場の樹冠と花壇の余白、道幅に合わせた草の除外を確認する。浅瀬の到達・深い海の拒否、ダッシュ速度・水中の減速・高速移動時の衝突も対象とする。同じrAF時刻のフレームが続いても走行アニメーションの重みを破損しないことを、GLBを使った回帰テストでも確認する。広域経路の区間内衝突、全4棟の入口到達、無効な目的地、古い保存形式、入口の内向き通過、一度だけの表示、閉じた直後の抑止、離れた後の再入館を対象とする。

ブラウザ検証と画像・動画の記録は`output/playwright/`（Git管理対象外）。PC 1440×900 / 1920×1080、スマホ390×844で全面表示・横はみ出しなしを確認した。全4棟の徒歩入館は入口外側からキーボード操作、タップ入館は初期広場から各入口への実経路で確認した。人物は近接した待機・歩行の複数姿勢でも確認した。

## 道路・中央広場・ジャンプの改修（2026-10-23）

道路のリボンを個別に重ねる描画をやめ、polygon-clipping（MIT）の和集合で一続きの舗装を作る。交差点の内側の角を丸め、舗装の外側との差分だけを縁石として押し出す。交差点を横切る縁石や同じ高さの路面の重複はなくす。石張りは世界座標で連続する目地、石ごとの色差、微細な粒と凹凸を持つ。追加ライブラリの出典: https://github.com/mfogel/polygon-clipping 。

主街路の海側の端は砂浜に届く前で止め、海岸から約7m内側を回る幅2.2mの遊歩道へ接続。全街路が平らな乾いた地面の上で一つにつながることを検証する。中央広場は半径3.8mを維持し、同心円と放射状の石張り、コーラルの縁取り、小さな真鍮色の方位模様を加えた。広場に障害物は追加していない。

ベンチ8基、街灯33基、既存の看板は、道路の実際の曲線と幅から位置を算出。ベンチと看板は通りへ向け、足元に接地した敷石を置く。交差点・建物・池・他の家具を避け、回転後の家具の範囲から衝突を生成する。看板に添えた鉢は看板の後ろへ移し、舗装を空ける。「りおまる」と重なる位置の街灯も避ける。広場上の電球は高さ3.8mの2本の固定支柱間のケーブルから吊るし、足元に台座と固定金具を追加。海辺で浮いていた2本の木も、斜面に置かれないよう修正した。

## Rapierによる自転車の物理走行・前輪操舵（2026-10-24）

描画は既存のThree.jsのまま、Apache-2.0の `@dimforge/rapier3d-compat` 0.21.0を追加。Rapierの `DynamicRayCastVehicleController` に前後2輪を設定し、85kgのダイナミックな車体へ後輪の駆動力、前輪の操舵、両輪のブレーキ、接地とサスペンション、タイヤの横方向の摩擦を適用する。車体はCCDを有効にし、120Hzの固定刻みで計算する。自由な二輪バランスのシミュレーターではなく、探索向けの転倒防止補助を持つ。車体のピッチ・ロールを物理側で安定させ、速度と実際の旋回角速度から最大約12.6度の見た目のバンクを生成する。

`lib/world-bike-physics.ts`がWASMの初期化、地形の三角形メッシュ、桟橋・スロープ、既存の建物・木・池・街路家具・手すりの固定コライダー、車体と2輪、固定刻みと破棄を管理する。地形は既存の海底高さと道の配置から生成。海岸には浅瀬の境界に沿ったコライダーを置き、桟橋の入口を開ける。港以外の深い海に入り込まない最終チェックも既存の海岸ルールから維持する。木やベンチを動かしたり、船を操作したりする機能は追加していない。

操作はユーザーが選んだW／↑で前進、S／↓でブレーキ・後退、A/D／←→でハンドル。入力を離すと惰性で進み、Sで制動、押し続けると低速で後退する。E／画面のボタンで降車、Escape・画面離脱・詳細表示では停止する。前進の目標上限は約6m/s、後退は約2.2m/s、浅瀬の目標上限は既存どおり1.1m/s。速度に応じて操舵角を約37度から約26度へ抑える。

タップ移動はA*の経路を先読みして操舵する。微小な格子の角をその場で折れる移動から、先読み点へ向かう物理的な旋回へ変更。経路の区間上へ進んだ場合も進捗を更新し、小さい曲がり角の周囲を回り続けないようにする。目的地へ近づくと減速し、約16cm以内で停止する。全4棟は入口前で降りてから従来の徒歩で入館する。

自転車は前輪・フォーク・泥よけ・ハンドル・前かご・前照灯を独立した操舵グループへ分け、ヘッドチューブの位置を支点として一緒に回す。前後輪の回転と上下位置はRapierから取得。人物は上体を操舵に合わせてひねり、同じ支点で計算した左右のグリップへ両腕を解く。タイヤの実回転からペダルと足を動かす。Reduced Motionではバンクと車輪・ペダルの回転を抑える。徒歩のジャンプ・歩行速度・既存のHTMLコンテンツは継続する。
